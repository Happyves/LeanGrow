It would be interesting how to obtain partial embedding in our embedding algos (idea : for all combinations of assumptions of a thm, add hypotheses of these type to a fake LCtx, run the embed algo, then when we produce the term, build a function that maps the artificially added assumptions to the term in which the fvars of the fake context corresponding to these assumptions are replaced by appropriate bvars).
Specific idea related to this, based on an example to be generalized, for to_the_moon : in order to use, say `Nat.rec`, in to_the_moon, we could proceed as follows. We may not even need a Nat in ltx to try this, since we can use any constant for the induction to apply on, but it's propably reasonable to try `Nat.rec` only when there's a Nat in ltx. Choose either the base case or the induction step to work on. In the base case, we run to_the_moon up to some arbitrary point where we get a ltx decl that can be eta-factored by `0` : we then let the factor become the motive for `Nat.rec`, and solve the induction step with it. If we start working on the induction step case, ... we're kind of screwed. If we worked with `Nat.casesOn`, we'd introduce some fake `n` to the context (which shouldn't appear in any other context), run to_the_moon up to some arbitrary point where we get a ltx decl that can be eta-factored by `.succ n` (getting `.succ n` into the context is a problem in the first place, as this won't happen if we grow only with theorems, so the `Nat.succ` will never be attempted to embed in the ltx). Then, similarly, we'd get our motive and attempt to prove the base case.
