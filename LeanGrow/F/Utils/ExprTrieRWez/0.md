In a forward step, we'd search for occurences of the pattern of one of the sides of the eq, and then add a new term to ltx as follows: in the tree, at the location of the pattern, we insert the other - equal - pattern with a new index. The new index will be a new gnode which has a value, ie. the term of type the rewritten expression. It seems I didn't distinguish between gnodes from the initial ltx which don't have a value and those we add as a result of applying thoerems, which will correspond to `let`s. Gnodes obtained via rewrites should have values that are obtained via `Eq.ndrec`.
