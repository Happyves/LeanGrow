

When using CExprTries as discriminaiton keys in SetTries:
We should only consider, for a given thm, the hypotheses that require a term that is not a sort. The reason is that, for example, for polymorphic thms with a hypothesis `a : Type _`, if queried in a context where hyps are satisfied for a concrete type for `a`, then the query will still fail as `a : Type _` won't be *explicitely* in the query.
